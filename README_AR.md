# NEARBY — Roblox Proximity Voice Starter

هذه نسخة بداية عملية للموقع، وليست نظام الصوت النهائي بعد.

## الموجود في هذه النسخة

- لوحة تحكم عربية بتصميم داكن متجاوب.
- إنشاء كود تحقق لحساب Roblox.
- التحقق من ظهور الكود في وصف الحساب العام.
- حفظ الحسابات الموثقة مؤقتاً في ذاكرة Node.js.
- رادار يستقبل مواقع اللاعبين عبر Socket.IO.
- سكربت Roblox ServerScriptService لإرسال مواقع اللاعبين.
- حماية أولية لنقطة استقبال بيانات Roblox بمفتاح سري.

## المتطلبات

- Node.js 20 أو أحدث.
- حساب Roblox وتجربة داخل لعبة تملك صلاحية تعديلها.
- تفعيل Allow HTTP Requests من إعدادات اللعبة.
- للاستضافة العامة: دومين وHTTPS.

## التشغيل المحلي

1. فك ضغط المشروع.
2. افتح المجلد في VS Code.
3. افتح Terminal داخله.
4. نفّذ:

   ```powershell
   npm install
   ```

5. انسخ `.env.example` إلى ملف اسمه `.env` وعدّل `ROBLOX_INGEST_SECRET` إلى قيمة طويلة عشوائية.
6. شغّل:

   ```powershell
   npm start
   ```

7. افتح `http://localhost:3000`.

ملاحظة: Node.js لا يقرأ ملف `.env` تلقائياً في هذا المشروع. لتشغيل محلي سريع، عرّف المتغير قبل التشغيل في PowerShell:

```powershell
$env:ROBLOX_INGEST_SECRET="ضع-هنا-سراً-طويلاً"
npm start
```

## ربط حساب Roblox

1. اكتب اسم المستخدم الصحيح في الموقع.
2. اضغط إنشاء كود التحقق.
3. افتح رابط ملف Roblox الذي يظهر.
4. أضف الكود إلى خانة About / الوصف في الملف الشخصي واحفظ.
5. ارجع للموقع واضغط تحقق من الحساب.

إذا لم يظهر التغيير فوراً، انتظر قليلاً ثم أعد المحاولة. بعض تحديثات الملف الشخصي قد تتأخر أو لا تكون متاحة عبر واجهة Roblox العامة.

## ربط لعبة Roblox

1. افتح `roblox/ServerScriptService.server.lua`.
2. غيّر `ENDPOINT` إلى عنوان السيرفر العام مع HTTPS.
3. ضع نفس قيمة `ROBLOX_INGEST_SECRET` في `SHARED_SECRET`.
4. أنشئ Script داخل `ServerScriptService` والصق الكود.
5. فعّل `Allow HTTP Requests` في إعدادات اللعبة.
6. انشر اللعبة وشغّل سيرفر تجريبي.
7. خذ `game.JobId` من السجل أو أضف واجهة تعرضه، ثم أدخله في حقل Server ID بالموقع.

## حدود النسخة الحالية

- الصوت الحقيقي غير مطبق بعد. طلب إذن المايك وحده لا ينشئ اتصالاً صوتياً.
- WebRTC يحتاج signaling ورسائل offer/answer/ICE، وإدارة peers، وSTUN/TURN عند الحاجة.
- Discord OAuth2 غير مطبق بعد؛ يلزم إنشاء تطبيق Discord وتسجيل Redirect URI وحفظ Client Secret في السيرفر فقط.
- التحقق من Roblox بالكود في الوصف طريقة إثبات ملكية بسيطة، لكنها ليست بديلاً عن OAuth الرسمي.
- البيانات والحسابات محفوظة في الذاكرة فقط وستضيع عند إعادة تشغيل السيرفر.
- لا تنشر هذا المشروع للعامة قبل إضافة قاعدة بيانات، حدود للطلبات، حماية جلسات، HTTPS، وإدارة أسرار مناسبة.
- رادار هذه النسخة يعرض الإحداثيات نسبةً إلى مركز ثابت، وليس موقع اللاعب المحلي بعد. نضيف إحداثيات اللاعب المحلي وحساب المسافة في المرحلة التالية.
